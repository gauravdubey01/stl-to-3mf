Installer Return Codes

The STL to 3MF Converter installer is built with Inno Setup 6.

Inno Setup exits with the following standard codes. Scenarios not listed below (e.g. disk full, network failure) are reported generically as code 1, since Inno Setup does not emit distinct codes for those conditions — they appear in the installation log.

CodeScenarioDescription
0Installation successfulInstaller completed without errors
1Installation failedGeneric failure — includes cancelled by user, application already exists, disk full, network failure, reboot required, package rejected, and other errors. See setup log for details.

Application Exit Codes

STL to 3MF Converter.exe is a Windows Forms GUI application. It does not return meaningful exit codes when launched directly — it always exits with code 0.

Log File

Inno Setup logs are written to %TEMP%\Setup Log*.txt for troubleshooting installation failures.
