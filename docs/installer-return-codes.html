Installer Return Codes

The STL to 3MF Converter installer is built with Inno Setup 6. The following exit codes are defined:

CodeScenarioDescription
0Installation successfulInstaller completed without errors
1Installation cancelled by userUser cancelled the installation before completion
2Application already existsA previous version of the application is already installed on the device
3Installation already in progressAnother installation is already running; only one instance is allowed
4Disk space is fullInsufficient disk space to complete the installation
5Reboot requiredA system restart is required before installation can proceed
6Network failureA network-related error occurred (e.g., download failure, timeout)
7Package rejected during installationInstallation rejected due to a security policy on the device
100Miscellaneous install failureAny other installation error not covered above. See setup log for details.

Log File

Inno Setup logs are written to %TEMP%\Setup Log*.txt for troubleshooting installation failures.
