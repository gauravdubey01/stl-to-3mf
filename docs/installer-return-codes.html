Installer Return Codes

The STL to 3MF Converter installer is built with Inno Setup and returns standard Windows installer exit codes:

CodeMeaning
0Installation completed successfully
1Installation was aborted by the user
2Installation failed due to an error (see log)
3Installation was cancelled by user or system

Application Return Codes

STL to 3MF Converter is a GUI application (Windows Forms) and does not return meaningful exit codes when launched normally. It always exits with code 0.
